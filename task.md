Заключается в разработке на языке С++ консольной программы, позволяющей пользователю ввести логически связанный набор данных. В качестве набора данных выступает информация о пациенте больницы, описываемого следующей структурой:

struct Date {

int dd;

int mm;

int yyyy;

};

struct Patient {

string passport; // ss ss-nnnnnn

string name; // any string

Date birth_date; // yyyy-mm-dd

string phone; // +X(XXX) XXX-XX-XX or X(XXX) XXX-XXXX

double temperature; // XX.XX

};

В комментариях описан корректный формат вводимых данных.

Программа должна учитывать, что пользователь может в любой момент опечататься (ввести любые некорректные данные) и корректно обработать эту ситуацию, предложив ему ввести данные повторно.

Отчёт предоставляется в электронном виде. Он должен содержать:

    Описание полученного задания.

    Исходный код программы.

    Наборы исходных данных, на которых проверялась программа и результаты ее работы.

За работу выставляется оценка в баллах. Максимальная оценка — 100 баллов. В ходе оценивания работы преподавателем предлагаются различные наборы входных данных, за каждый набор, который программа обработала некорректно от оценки снимается 20 баллов. В случае, если студент не может пояснить какие-либо использованные в программном коде конструкции или использованные приемы, работа оценивается в 0 баллов. В случае, если студент не может изменить программу по требованию преподавателя - оценка снижается на 80 баллов.

На выполнение работы студенту дается 2 недели, причем процедура приема работы осуществляется 1 раз в неделю.
